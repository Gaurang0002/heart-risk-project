ABOUT THE SYSTEM

A Machine Learning Approach to Heart Risk Analysis

This system uses machine-learning techniques to analyze selected heart-health factors and generate an individual prediction. LIME is used to provide an explanation of the factors contributing to the model's prediction.

Health Factors

The system analyzes selected input features related to heart disease prediction.

Machine Learning

Multiple machine-learning algorithms are trained and evaluated for heart-risk prediction.

Explainable Prediction

LIME helps explain which features contributed to an individual model prediction.
